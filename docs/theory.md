# Теоретические основы

Три принципа (адаптивность, модельная осознанность, human-in-the-loop) опираются на профилирование данных и замыкаются оценкой через прокси-модель.

```mermaid
flowchart LR
    P["Профилирование<br/>данных"] --> S["Кандидатные<br/>стратегии"]
    S --> V["Интерактивная<br/>визуализация"]
    V --> M["Оценка через<br/>прокси-модель"]
    M --> H{"Решение<br/>пользователя"}
    H -->|"принять"| N["Следующий шаг"]
    H -->|"другая стратегия"| S
```

## Три принципа

### Адаптивная предобработка

Универсального решения нет (Fan et al., 2021; Bilal et al., 2022), поэтому стратегия выбирается динамически по автоматически вычисленному профилю:

1. **профилирование**: определение структурных свойств данных;
2. **генерация кандидатов**: набор стратегий, релевантных профилю;
3. **ранжирование**: сортировка стратегий по влиянию на качество прокси-модели.

Предобработка из «чёрного ящика» становится управляемой и измеримой частью процесса.

### Модельная осознанность (model-aware preprocessing)

Каждый шаг оценивается не в изоляции, а по влиянию на последующую модель. Это развивает замкнутый цикл обратной связи из Auto-Prep и Preptimize и устраняет разрыв между предобработкой и моделированием.

### Human-in-the-loop

Модуль автоматизирует рутину (статистики, поиск проблем, рекомендации), но окончательное решение остаётся за пользователем на основе понятных визуальных и количественных метрик (Dhummad, 2025).

## Профилирование данных

Профиль формируется на двух уровнях.

| Уровень | Что фиксируется |
|---|---|
| **Набор данных** | Размерность, доля пропусков, наличие дубликатов, баланс целевой переменной, временная структура |
| **Столбец** | Семантический тип, доля и характер пропусков, форма распределения, наличие выбросов, кардинальность, корреляция с целевой переменной |

Семантические типы: числовой непрерывный, числовой дискретный, категориальный, бинарный, дата/время, текстовый идентификатор.

**Распределение** оценивается через асимметрию, эксцесс и критерии нормальности (например, Шапиро — Уилка для небольших выборок). Для временных рядов дополнительно проверяются стационарность (расширенный тест Дики — Фуллера, ADF), тренд и сезонность.

Результаты профилирования питают модуль рекомендаций и служат материалом для визуализаций EDA.

## Оценка влияния через прокси-модель

В Auto-Prep стратегии ранжируются по метрикам быстрых моделей (наивный Байес, дерево решений). В Preptimize комбинация «предобработка + модель + гиперпараметры» оптимизируется по RMSE генетическим алгоритмом.

Для проектируемого модуля принята **облегчённая версия**:

1. выбранная стратегия применяется (или рассматривается в режиме предпросмотра);
2. на обучающей выборке обучается быстрая прокси-модель;
3. целевая метрика сравнивается с базовым значением.

| Тип задачи | Метрики |
|---|---|
| Классификация | accuracy, F1 |
| Регрессия | RMSE, MAE |

Пользователь видит не абстрактные рекомендации, а измеримый эффект конкретного решения.

## Итог

Профилирование задаёт контекст, адаптивные методы предлагают релевантные стратегии, интерактивная визуализация обеспечивает прозрачность, а прокси-модель делает процесс модельно-осознанным. Конкретные методы описаны на страницах [Пропуски и выбросы](data-quality.md) и [Визуализация и EDA](visualization.md).
